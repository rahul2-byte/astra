              CASE / 03                            RecSys Pipeline · Two-Stage Retrieval & GBDT Reranking             
Reciprocal Rank Fusion

            Multi-Stage Movie Recommendation System           

            Production-grade candidate generation funnel seeded with user watchlist signals. Combines sparse text retrieval, latent matrix factorization, and deep semantic embeddings before LightGBM reranking.           

filter_alt               Candidate Generation to Reranking Funnel             

              Single-retriever architectures suffer from systemic cold-start or novelty traps. This design implements four distinct recall sources (Collaborative Filtering, Dense Semantic Vectors, Lexical BM25, and Graph Popularity). Their outputs are blended using constant-discount reciprocal rank fusion (k=60) to deliver a high-signal candidate pool to a point-wise LightGBM ranker.
