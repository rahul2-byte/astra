01 Problem Domain

            Why I Built It: Eliminating Financial Hallucination in Equities           

              Contemporary Large Language Models demonstrate extraordinary fluency when synthesizing corporate filings, earning transcripts, and analyst consensus. However, when deployed directly as investment analysts, they exhibit catastrophic vulnerabilities: they fabricate balance sheet items, miscalculate price-to-earnings or PEG multiples by 20% to 50%, and present spurious valuation narratives with absolute linguistic confidence.             

              In equity analysis, an approximate computation is not merely inaccurate—it is dangerous. Traditional financial software maintains absolute mathematical accuracy but lacks semantic flexibility; generative models offer synthesis but cannot be trusted with an income statement.             

Core Design Axiom

                "Language models must never compute arithmetic, estimate multiples, or quote numerical statistics without a verifiable pointer to an authoritative JSON payload node."               

              FIN-AI solves this through strict decoupling: an authoritative Python mathematical core performs all ratio, discounted cash flow (DCF), and solvency checks using pure decimal arithmetic. The LLM is restricted to semantic context parsing within a bounded loop (≤ 5 iterations), while an automated post-generation assertion pipeline rejects reports with unverified claims.

core/valuation_engine.py Python 3.11 
from decimal import Decimal
from pydantic import BaseModel, Field, field_validator

class DeterministicValuation(BaseModel):
    ticker: str
    market_price: Decimal = Field(..., gt=0)
    eps_trailing: Decimal
    book_value_per_share: Decimal
    free_cash_flow: Decimal
    shares_outstanding: int = Field(..., gt=0)

    @property
    def pe_ratio(self) -> Decimal:
        # Pure python decimal arithmetic: no floating point skew
        if self.eps_trailing <= 0:
            return Decimal("0.0")
        return (self.market_price / self.eps_trailing).quantize(Decimal("0.01"))

    @property
    def fcf_yield(self) -> Decimal:
        market_cap = self.market_price * Decimal(self.shares_outstanding)
        return ((self.free_cash_flow / market_cap) * 100).quantize(Decimal("0.01"))

# Schema passed to model guarantees synthesis only references validated keys
03 Rigorous Boundary

            Deterministic vs Generative Decoupling           

            To ensure zero arithmetic skew, FIN-AI isolates responsibilities into strictly compartmentalized modules. The generative model is treated as a context interpreter, never as a compute kernel.           

Pipeline Vector FIN-AI Architecture Unconstrained LLM Agent
Valuation Math                     Pure Python Decimal arithmetic. 0.00% calculation divergence.                                        In-prompt token arithmetic. 18–35% catastrophic error rate on compound DCF.                   
Corporate Filings                     Timestamped Upstox/NSE filings stored with sha256 payloads.                                        Unstructured web-search snippets prone to sponsored blogs and outdated SEC data.                   
Hallucination Gate                     Automated AST & regex verification rejects numbers not matching snapshot nodes.                                        No citation verification. Factual claims accepted directly as truthful.                   
Loop Termination                     Hard ≤ 5 iterations ceiling. Invariant stops runaway billing loops.                                        Unbounded dynamic loop depth resulting in multi-dollar API stalls.

05 Engineering Reality

            Practical Engineering Limitations           

              Maintaining an honest technical disclosure is paramount in quantitative engineering. FIN-AI is designed with clear explicit boundary constraints:             

  • verified_user
    Not SEBI Registered Investment Advice: The system is a research harness and developer prototype. It provides zero market timing recommendations, buy/sell targets, or predictive alpha. It strictly formats and cross-verifies existing public disclosures.
  • api
    Upstream Provider Flakiness: While the mathematical verification engine is 100% deterministic, Upstox and free-tier financial APIs can experience latency spikes, schema alterations, or missing trailing data for SME indices.
  • lan
    Scoped FastAPI Microservice: The optional web server is intentionally constrained to health probes and raw snapshot caching, delegating heavy-weight analysis to local processes to maintain zero-cost hosting feasibility.
